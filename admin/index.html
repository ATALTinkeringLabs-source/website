Sign in with a GitHub access token. It stays in this browser and is only ever sent to GitHub.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new
  2. Resource owner: your account or organisation. Expiration: 90 days or less.
  3. Repository access: Only select repositories → pick this website repo.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate, copy the token and paste it above.
